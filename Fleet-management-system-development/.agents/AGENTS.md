# Agent Instructions

## Documentation Maintenance Rule
Whenever you make any changes to the codebase (such as creating new screens, adding packages, modifying layouts, or updating configurations), you MUST automatically update the following documentation files in the `driver_mobile/` project:
1. `CHANGELOG.md` - Append a entry for the new version/changes.
2. `KNOWLEDGE_BASE.md` - Keep folder structure, color palette, design systems, screens, and integration guides updated with the new implementation details.

Always verify that these documentation updates are completed before concluding your work.
